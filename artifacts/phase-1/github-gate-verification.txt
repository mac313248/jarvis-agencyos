# Acceptance #45 — GitHub Merge-Gate Verification

Acceptance #45 (12_ACCEPTANCE_AND_IMPLEMENTATION.md): "Cursor builder cannot merge failed CI."

## What the workflow proves
`.github/workflows/phase-1.yml` proves a CI workflow EXISTS and runs the
Phase 1 checks (SOT guard, clean migrate, full suite) on push/PR to main
and to `phase-1/**` branches. The workflow YAML alone does NOT prove that a
failed/missing required CI check blocks merge to main. That requires a
GitHub branch-protection / ruleset enforcement, which is repository
configuration, not code.

      curl -sv https://api.github.com
